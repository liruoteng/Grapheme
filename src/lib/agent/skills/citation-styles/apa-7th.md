# APA 7th Edition Citation Style

## In-Text Citations

### One Author
- Parenthetical: (Smith, 2020)
- Narrative: Smith (2020) found...

### Two Authors
- Parenthetical: (Smith & Jones, 2020)
- Narrative: Smith and Jones (2020)

### Three or More Authors
- First citation and all subsequent: (Smith et al., 2020)

### Multiple Works
- (Smith, 2020; Jones, 2019; Lee, 2021)
- Order alphabetically by first author

## Reference List Format

### Journal Article
```
Author, A. A., & Author, B. B. (Year). Title of article.
    Title of Periodical, volume(issue), page–page. https://doi.org/xxxxx
```

### Book
```
Author, A. A. (Year). Title of work: Capital letter also for subtitle
    (Edition). Publisher. https://doi.org/xxxxx
```

### Conference Paper
```
Author, A. A. (Year, Month Day–Day). Title of contribution.
    Conference Name, Location. https://doi.org/xxxxx
```

### Website
```
Author, A. A. (Year, Month Day). Title of page. Site Name.
    https://url
```

## BibTeX Format for APA
```bibtex
@article{smith2020,
  title = {Title of the Article},
  author = {Smith, Alice A. and Jones, Bob B.},
  year = {2020},
  journal = {Journal Name},
  volume = {10},
  number = {2},
  pages = {100--115},
  doi = {10.xxxx/xxxxx}
}
```

## Key Rules
- Hanging indent for all references
- Alphabetical order by first author's last name
- Use sentence case for article titles
- Use title case for journal names
- Include DOI when available
